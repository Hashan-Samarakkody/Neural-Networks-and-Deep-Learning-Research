# Predicting Tourism Recovery Duration Following Natural Disasters in Sri Lanka

Regression pipeline for estimating the number of months for Sri Lanka tourist arrivals to recover to 90% of pre-disaster seasonal baseline after a physical natural disaster (2000–2025).

## Setup

```bash
cd pipeline
pip install -r requirements.txt
```

## Data

Place the following files in `pipeline/data/raw/`:

| File | Source |
|------|--------|
| `Disaster data.xlsx` | EM-DAT Sri Lanka physical disasters (2000–2025) |
| `tourist_arrivals.csv` | SLTDA monthly tourist arrivals — columns: `year`, `month`, `tourist_arrivals` |

## Run

```bash
cd pipeline
python run_experiments.py
```

Outputs are written to `pipeline/outputs/`:

| Path | Contents |
|------|----------|
| `outputs/results/experiment_results.csv` | MAE / RMSE / R² with 95% bootstrap CI for all models |
| `outputs/results/wilcoxon_tests.csv` | Wilcoxon signed-rank p-values |
| `outputs/results/target_distribution.json` | Recovery duration distribution statistics |
| `outputs/results/rq_summary.json` | RQ1–RQ4 answers |
| `outputs/results/sensitivity_analysis.csv` | 9-cell threshold × baseline-window grid |
| `outputs/results/shap_importance_ExpB_XGBoost.csv` | TreeSHAP feature ranking |
| `outputs/figures/` | SHAP beeswarm, dependence plots, correlation matrix, distribution histogram |

## Reproducibility

All experiments use `seed=42` (global `np.random.seed` and per-estimator `random_state`). Results are deterministic given the same input data.

## Experiments

| Experiment | Dataset | Validation | N (events) |
|------------|---------|------------|------------|
| A | Physical disasters outside 2019–2022 | LOOCV; 12-month buffered LOOCV; leave-one-year-out; expanding window | 46 |
| B | All events including 2019–2022 | Chronological split (train ≤ 2018, test ≥ 2019) | 60 (37 train / 23 test) |

## Key Findings

> Generated by `src/make_readme.py` from `pipeline/outputs/results/paper_numbers.json`; run at commit `0761f59` with pinned versions: True.

- **Sample:** 86 raw EM-DAT records → 80 physical → 65 after clustering → 60 with a valid target.
- **Target:** 38 of 60 events have T_rec = 0; mean 2.9 months; 10 right-censored at 12 months, all in 2019–2022 (10 of 14).
- **Experiment A (LOOCV, N=46):** best TwoStage (MAE 0.75), then RandomForest (1.06); predicting zero gives 1.11. Under 12-month buffered LOOCV the best MAE is 1.14 (TwoStage).
- **Experiment B (chronological, N=23 test):** best TwoStage (MAE 3.50).
- **Tests (sign-flip permutation, Holm):** XGBoost vs NaiveMean p_holm 0.0021; vs NaiveMedian p_holm 1.0.
- **Survival (Experiment B C-index):** CoxPH 0.6882, RandomSurvivalForest 0.5699, DiscreteHazard 0.8898 (`survival_results.csv`).
- **Permutation importance (Experiment A):** Economic_Condition_Index (0.8845 months MAE increase).

## Configuration

All experimental settings are in `pipeline/configs/model_config.yaml`:
- Recovery threshold: 90% of seasonal baseline (UNWTO benchmark)
- Baseline window: 3 non-crisis reference years
- Crisis years: 2019 (Easter attacks), 2020–2022 (COVID + economic crisis)
- Hyperparameter grids for XGBoost, RandomForest, SVR, Ridge

## Known Limitations

1. **Target validity:** non-zero targets coincide with national shocks (2007–2009, 2023) and all censored events fall in 2020–2022; see `confounding_sensitivity.csv`.
2. **Zero-inflation:** 38 of 60 targets are zero; the two-stage model was added post hoc with fixed C=1, α=1.
3. **Dependence:** events are closely spaced; buffered and leave-one-year-out results are the primary evidence, plain LOOCV is optimistic.
4. **Version sensitivity:** XGBoost results depend on library versions; see `docs/VERSION_SENSITIVITY.md`. Run only in the pinned environment.
5. **Static DTII** shares and annual macro values (2024–2025 are projections).
